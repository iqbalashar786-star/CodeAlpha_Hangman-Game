# Hangman Game (Python) - CodeAlpha Internship Task

A modular, interactive command-line Hangman game built using Python as part of the CodeAlpha Internship.

## Features
- **Dynamic ASCII Stages:** Visual gallows update after every incorrect guess.
- **Input Validation:** Restricts input to single alphabetical characters and ignores invalid inputs/symbols.
- **Duplicate Guess Handling:** Alerts the user if a letter has already been chosen without deducting lives.
- **State Tracking:** Clear visibility of remaining attempts, guessed letters, and current word completion.

## How to Run
1. Make sure Python 3.x is installed.
2. Run the game via terminal:
   ```bash
   python hangman_game.py
